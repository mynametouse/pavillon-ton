# pavillon-ton

Klänge für den Grenzland-Modus von [Pavillon Ratscher](https://mynametouse.github.io/pavillon-ratscher/): echte Songs fürs Radio,
Filmmusik bei Missionen, Aufnahmen der Orte. Alles unter freien Lizenzen (CC0, CC BY, gemeinfrei) – Nachweise in
[CREDITS.md](CREDITS.md), zum Probehören: <https://mynametouse.github.io/pavillon-ton/>.

Das Spiel lädt die Dateien von dieser Seite (GitHub Pages, derselbe Host wie das Spiel), damit die Seite des Spiels unter ihrer
Grenze von 1 GB bleibt. Ordner: `radio/`, `score/`, `orte/`; `index.json` listet alles mit Quelle und Lizenz.
Keine Schlüssel, keine privaten Daten.
